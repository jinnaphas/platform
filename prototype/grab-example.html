ถอดบทเรียนทำไม Grab = Ecosystem Capitalism (ศัพท์จากสไลด์ Evolution)

AdvantageEcosystem — คุณค่าเกิดจาก "ผลคูณข้ามบริการ" ไม่ใช่บริการเดี่ยว
Focusสร้างและขยายระบบนิเวศ — เพิ่มบริการ/พาร์ตเนอร์เข้ามาเสียบบนแกนเดิมเรื่อยๆ
Value Chainแบบ Ecosystem — หลายแพลตฟอร์มแชร์ Single ID · Wallet · เครือข่ายคนขับ · Data ร่วมกัน
Key Resourceพาร์ตเนอร์ มาตรฐาน ความเชื่อมั่น — ธนาคาร ประกัน ร้านค้า สายการบิน เข้ามาต่อเพราะเชื่อระบบ
วิธีหารายได้หลายก้อน — ค่าคอมทุกบริการ + การเงิน (สินเชื่อ/ประกัน/PayLater) + โฆษณา GrabAds + สมาชิก GrabUnlimited

เทียบยุคต่างจาก Uber (Platform Capitalism) ตรงไหน

  • Uber = 1 แพลตฟอร์มจับคู่ 2 ฝั่ง (ผู้โดยสาร ↔ คนขับ) — เก่งเรื่องเดียวให้สุด
  • Grab = หลายแพลตฟอร์มบนแกนร่วมเดียว — เรียกรถ อาหาร ของสด พัสดุ การเงิน ใช้ ID/Wallet/คนขับ/ข้อมูล ชุดเดียวกัน
  • ลูกค้าเข้ามาด้วยบริการเดียว แต่ถูก Cross-sell จนใช้ 3-4 บริการ — ต้นทุนหาลูกค้าของบริการใหม่ ≈ 0
  • แต้ม + Wallet ผูกทุกบริการ = Lock-in ทั้งระบบนิเวศ เลิกใช้ทีเดียวเสียหมด
  • ข้อมูลข้ามบริการสร้างธุรกิจใหม่ที่คู่แข่งทำไม่ได้ เช่น ปล่อยสินเชื่อจากข้อมูลรายได้จริง ของคนขับ/ร้านค้า

แผนภาพ: Ecosystem ของ Grab พร้อมเล่าเรื่อง — กดเล่นหรือหมุนล้อเมาส์เพื่อซูม
เส้นทางของระบบนิเวศ (ตามเลข ①–⑧): การใช้บริการ เงิน ข้อมูลข้ามบริการ ลากเพื่อเลื่อน · หมุนล้อเมาส์เพื่อซูม · คลิกเลขเพื่อกระโดดไปขั้นนั้น
